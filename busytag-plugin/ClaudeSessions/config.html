Claude Sessions

Shows what the busytag-claude daemon on this Mac reports: each Claude Code and Cowork session's status, and an orange flash when one needs your input. Set "transport": "app" in ~/.config/busytag-claude/config.json so the daemon leaves the USB port to this app.

Checking for the daemon…

The status only shows while this plugin is on the tag. To keep it there, make it the only enabled plugin, or give it a long display time.
